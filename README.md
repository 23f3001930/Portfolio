# Pragati Chandra Portfolio

A GitHub Pages-ready portfolio with a dark navy + orange visual style inspired by the card layout of the reference portfolio, but using Pragati's own content.

## Main files
- `index.html` — page structure and section order.
- `style.css` — design, colors, responsive layout and animations.
- `script.js` — renders the cards and interactions.
- `portfolio-data.js` — **the main file to edit when adding/updating content**.

## Section order
About → Education → Certificates → Projects → Internships → Skills → Achievements → Contact.

## Updating
Add/edit projects, certificates, internships, skills or highlights in `portfolio-data.js`. The page renders each item once automatically.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.


### Certificate folders
The Certificates section now includes AWS and Infosys folder-style cards. Each folder contains all supplied Google Drive credentials. The links are external Drive documents; no certificate names were invented because only the Drive URLs were supplied.
